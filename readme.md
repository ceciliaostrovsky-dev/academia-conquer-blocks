# 🎓 Academia Conquer Blocks - Frontend

Este proyecto es el desarrollo del Frontend para la plataforma educativa "Academia Conquer Blocks", diseñado como parte del Máster en Desarrollo Web Full Stack.

El objetivo principal de este proyecto es construir una interfaz web moderna, escalable y optimizada, aplicando las mejores prácticas de maquetación, arquitectura de estilos y herramientas de desarrollo profesional.

## ✨ Características Principales

- **Arquitectura Modular:** Uso de Vite y `vite-plugin-html-inject` para la inyección de componentes globales (Header y Footer), manteniendo el código HTML limpio y mantenible.
- **Estilos Avanzados con SCSS:** Implementación de variables, mixins (como control de breakpoints para Responsive Design) y anidamiento para un código CSS ordenado y sin redundancias.
- **Responsive Design:** Adaptación fluida a dispositivos móviles, tablets y escritorio.
- **Optimización para Producción:** Configuración de rutas absolutas dinámicas en `vite.config.js` para asegurar un despliegue perfecto y sin errores 404 en GitHub Pages.
- **Buenas Prácticas:** Código semántico, optimización de accesibilidad (atributos `alt`, eliminación de eventos en línea) y eliminación de deuda técnica.

## 🛠️ Tecnologías Utilizadas

- **HTML5** (Semántico y Accesible)
- **SCSS / CSS3**
- **JavaScript** (Vanilla)
- **Vite** (Entorno de desarrollo y empaquetador)
- **Git / GitHub** (Control de versiones)
